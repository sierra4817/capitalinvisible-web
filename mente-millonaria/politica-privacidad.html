Política de Privacidad

En Capital Invisible, la confidencialidad de tu información privada es tan importante como el patrimonio del que habla este libro. Esta Política de Privacidad describe cómo se recopilan, utilizan y protegen tus datos cuando adquieres y utilizas La Mente Millonaria es Invisible.

1. Responsable del Tratamiento de Datos

El responsable del tratamiento de tus datos personales recopilados a través de esta web es:

  • Titular: Fermín Alberto Sierra (Capital Invisible)
  • Domicilio: Versoix, Ginebra, Suiza
  • Correo de contacto para asuntos de privacidad: info@capitalinvisible.online

2. Datos que Recopilamos y Finalidad

Esta página del sitio no incluye formulario de suscripción propio: el único dato personal que se procesa es el necesario para completar la compra a través de Payhip.

  • Datos de compra: Payhip, como plataforma de pago, recopila el correo electrónico y los datos de pago necesarios para procesar tu adquisición y darte acceso al contenido digital. Esta web no almacena ni tiene acceso directo a tus datos de pago.
  • Preferencias de lectura (solo en tu navegador): El lector/reproductor de esta web guarda localmente, mediante localStorage, tu capítulo y posición de reproducción, el volumen, la velocidad y el tema (claro/oscuro) elegidos. Estos datos nunca salen de tu navegador, no se envían a ningún servidor y se eliminan si borras los datos del sitio.
  • Datos de navegación: Dirección IP y registros técnicos estándar del servidor de alojamiento (GitHub Pages), necesarios para el funcionamiento del sitio.

3. Base Legal para el Tratamiento

La base legal para el tratamiento de tus datos de compra es la ejecución del contrato de compraventa que aceptas al adquirir el producto a través de Payhip.

4. Conservación de los Datos

Esta web no mantiene una base de datos propia de clientes: los datos de compra los conserva Payhip conforme a su propia política de privacidad. Las preferencias de lectura guardadas en tu navegador permanecen hasta que tú las borres.

5. Proveedores y Destinatarios (Terceros)

No vendemos, alquilamos ni cedemos tus datos a terceros con fines comerciales propios. Para prestar este servicio, utilizamos las siguientes herramientas tecnológicas de terceros, que actúan como encargados del tratamiento:

  • Payhip: Plataforma de comercio electrónico que procesa la pasarela de pago segura y gestiona la entrega del producto de manera cifrada.
  • GitHub / GitHub Pages: Servidor tecnológico donde se aloja el código estático de esta web.

Algunos de estos proveedores tienen sede fuera del Espacio Económico Europeo (principalmente en Estados Unidos). En esos casos, la transferencia de tus datos se realiza acogiéndose a las garantías previstas por dichos proveedores (como cláusulas contractuales tipo u otros mecanismos reconocidos por el RGPD).

6. Tus Derechos

Si resides en la Unión Europea, el tratamiento de tus datos se rige por el Reglamento General de Protección de Datos (RGPD). Tienes derecho a:

  • Acceso a los datos que tenemos sobre ti.
  • Rectificación de información inexacta o incompleta.
  • Supresión ("derecho al olvido") de tus datos de nuestros sistemas.
  • Limitación u oposición al tratamiento.
  • Portabilidad de tus datos, cuando sea técnicamente posible.

Para ejercer cualquiera de estos derechos, escríbenos a info@capitalinvisible.online. Responderemos a tu solicitud en un plazo máximo de 30 días. Para asuntos relacionados con tu pago concreto, Payhip dispone de sus propios canales de soporte.

Si consideras que no hemos atendido correctamente tu solicitud, tienes derecho a presentar una reclamación ante la autoridad de control de tu país de residencia (en España, la Agencia Española de Protección de Datos — AEPD).

7. Cambios en esta Política

Nos reservamos el derecho de modificar esta política para adaptarla a novedades legislativas. Cualquier cambio significativo será publicado en esta misma sección.
